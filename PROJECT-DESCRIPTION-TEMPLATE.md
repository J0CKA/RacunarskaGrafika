# {Car Showroom}

{075/2023} - {Stefanovic Jovana}  
{3D model auto-salona izrađen u C++ i OpenGL okruženju. 
Projekat predstavlja 3D showroom sa više 3D modela automobila, postoljima, 
teksturama, osvetljenjem, point shadows efektom i 
framebuffer post-processingom.}

## Controls

{W} -> {kretanje kamere napred}  
{s} -> {kretanje kamere nazad}
{A} -> {kretanje kamere ulevo}
{D} -> {kretanje kamere udesno}

{PAGE UP} -> {pomeranje kamere nagore}
{PAGE DOWN} -> {pomeranje kamere nadole}

{LEFT ARROW} -> {rotacija kamere ulevo}
{RIGHT ARROW} -> {rotacija kamere udesno}
{UP ARROW} -> {pomeranje pogleda nagore}
{DOWN ARROW} -> {pomeranje pogleda nadole}

{1} -> {uključivanje/isključivanje point svetla}
{2} -> {uključivanje/isključivanje directional svetla}

{J / L} -> {pomeranje point svetla po X osi}
{I / K} -> {pomeranje point svetla po Z osi}

{U} -> {povećavanje intenziteta point svetla}
{O} -> {smanjivanje intenziteta point svetla}

{F} -> {uključivanje/isključivanje framebuffer post-processing efekta}
{H} -> {uključivanje/isključivanje point shadows}

{E} -> {pokretanje vremenske sekvence događaja}



## Features

### Fundamental:

[x] Model with lighting
[x] Two types of lighting with customizable colors and movement through GUI or ACTIONS
[x] {E} --- AFTER_2_SECONDS---Triggers---> {point light changes to red} ---> AFTER_2_SECONDS---Triggers---> {cars rotate faster}

### Group A:

[x] Frame-buffers with post-processing   
[ ] Off-screen Anti-Aliasing  
[ ] Parallax Mapping
[ ] Bloom with the use of HDR

### Group B:
[ ] Deferred Shading  
[x] Point Shadows  
[ ] SSAO

### Engine improvement:

[x] First-person camera movement through the showroom
[x] Camera rotation and vertical movement
[x] 3D car models
[x] Textured showroom environment
[x] Framebuffer rendering with post-processing
