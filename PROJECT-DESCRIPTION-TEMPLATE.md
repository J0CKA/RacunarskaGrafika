# SVEMIR

mi23075 - Jovana Stefanovic

3D prikaz Sunčevog sistema,s cena sadrži Sunce i osam planeta raspoređenih u prostoru.
U pozadini scene nalazi se skybox koji predstavlja svemir.


## Controls

ESC -> izlaz iz programa  
F2 -> uključivanje/isključivanje GUI-a  
W -> pomeranje kamere napred  
S -> pomeranje kamere nazad  
A -> pomeranje kamere ulevo  
D -> pomeranje kamere udesno  
Mouse -> rotacija kamere

## Features

### Fundamental:

[x] Model with lighting
[x] Two types of lighting with customizable colors and movement through GUI or ACTIONS
[x] E --- AFTER_2_SECONDS---Triggers---> promena boje Point svetla ---> AFTER_2_SECONDS---Triggers---> pomeranje Sunca

### Group A:

[ ] Frame-buffers with post-processing   
[ ] Off-screen Anti-Aliasing  
[ ] Parallax Mapping
[ ] Bloom with the use of HDR
